# Практична робота №1: Класи та об'єкти (Classes & Objects)
## Предметна область
Програма моделює предметну область **«Музичні інструменти»** (`Instruments`).

### Кожен об'єкт класифікується за:
* **назвою** (`name`) та **брендом** (`brand`): *Yamaha, Gibson, Pearl, Roland*.
* **сімейством** (`family`): *Strings, Woodwinds, Brass, Percussion, Keyboard*.
* **типом живлення**: акустичний або електронний (`isElectric`).
* **кількісними параметрами**: кількість струн (`stringCount`) та клавіш (`keyCount`).
* **поточним станом**: підключення до мережі (`isConnected`), налаштованість (`isTuned`) та рівень гучності (`currentVolume`).

## **Функціонал програми**

Програма є консольним застосунком з інтерактивним меню, що дозволяє керувати колекцією об'єктів класи Instruments (до N елементів) та взаємодіяти з їхньою поведінкою:

1. **Додавання інструментів (Add new):**

- *Ручний ввід: з валідацією логічних зв'язків (наприклад, перевірка відповідності кількості струн/клавіш залежно від типу та назви інструменту).*

- *Автоматична генерація: випадкове створення об'єкта з коректними параметрами.*

2. **Перегляд усіх об'єктів (Show all objects):**

*Форматований вивід списку інструментів у вигляді таблиці.*

3. **Пошук (Search for object):**

*Пошук інструментів за назвою, сімейством, брендом або типом (електричний/акустичний).*

4. **Демонстрація поведінки (Show behaviour):**

- *Tune() — налаштування інструменту (перевіряє живлення та відповідність кількості струн/клавіш).*

- *Play() — відтворення звуку (вимагає попереднього налаштування isTuned).*

- *Connect() — підключення електроінструменту до мережі.*

- *SetVolume() — зміна рівню гучності (0–100%) для електронних інструментів.*

5. **Видалення (Delete object):**

*Видалення обраного інструменту зі списку за номером.*
